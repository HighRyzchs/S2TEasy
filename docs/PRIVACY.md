# Privacy and local data

The desktop app stores settings/history in `%APPDATA%\s2teasy\s2teasy.json` on Windows. Session checkpoints and retained PCM audio live in its `sessions/` directory. Audio is mono PCM16 at 16 kHz. Exported WAVs have standard headers and a JSON sidecar with the corrected text, original recognition, model, language hint, and sample rate.

**On this computer:** history, vocabulary, recovery audio, and optional pronunciation examples. Audio and transcripts are unencrypted app files. Windows DPAPI protects API keys via Electron safeStorage; keys are not saved when OS encryption is unavailable. Legacy plaintext credentials are read for migration, but new writes require encryption. A corrupt settings file is preserved with an `.unreadable-<timestamp>` suffix before defaults are used. Session journals contain no credentials.

**To your chosen provider:** streaming sends PCM audio to router.audio; OpenRouter sends WAV clips and language hints (plus vocabulary prompts for audio chat models) to OpenRouter and its model provider. Those services have their own retention policies and billing. Local speech sends clips to the configured loopback service; that service's model-download and telemetry behavior is outside this app. Enabling a local engine does not alter other software's policies.

**Recovery:** finalized text is saved before paste. Recovery audio is enabled by default and disclosed in the interface. Successfully inserted audio is deleted unless successful-take retention is enabled. Failed/interrupted/cancelled audio remains for recovery and expires after the configured 1–30 days. Cleanup runs at startup and hourly while idle; it cannot run while the app is closed. Temporary files are ordinary files; power loss can lose the latest unflushed audio. If disk writes fail, an error is shown; recovery cannot be guaranteed on a failed disk.

**Training:** successful-take retention is opt-in and local. No training API, voiceprint, background training, or dataset upload is implemented. Corrections change transcript text and explicit vocabulary rules. Whole-take WAV/text exports require a user-selected save location. Deletion and retention in this app do not delete files you exported or data already sent to a provider.

**Practice summaries (development build):** recognition match counts are computed locally from completed practice entries' original text and intended labels, grouped by model. They make no additional provider calls and store no new audio or profile. Deleting History changes the available counts. The proposed contextual correction and speech-cue modules are not active features.

**Deletion:** deleting History entries removes their session metadata and audio. Clearing History removes the visible retained sessions. History keeps up to 400 sessions, deleting older app-managed recordings. OS backups, provider logs, exported files, and unreadable-store backups must be managed separately.

The app contains no remote analytics integration. Usage & spend stores provider/model identifiers, request IDs, timestamps, reported costs, audio duration, latency, retry counts and outcomes in local `usage.json` (latest 10,000 calls). It stores no transcript, recording or API key. Clearing History does not remove this separate metrics log. CSV export uses a user-selected location. Costs missing from a response remain unknown. Update checks contact GitHub when manually requested or when auto-update is enabled. Automatic updates are off by default. Do not submit API keys, real dictation history, or private audio in public bug reports.

Overlay images are stored inside your local settings after resizing. The website and app overlay editor can request microphone access when you click “Use my microphone”; this preview only measures volume locally. It does not store or upload audio. Stop, End preview, or leaving the editor releases the microphone. The website’s simulated update controls never download an executable.

**Review and word examples:** the HUD can copy the visible transcript and finish into a local editor. Suggested Vocabulary rules require an explicit click. Retained audio plays through an app-local protocol, without uploads or exposing file paths. When real provider timestamps exist, you can explicitly save a small word clip as a labeled Voice practice take; it follows the configured retention period. Word-timing requests are optional and off by default for compatibility. Neither corrections nor labeled clips trigger acoustic model training.

**Stop and cancel:** Stop continues microphone capture for the configured tail (600 ms by default). Cancel stops capture immediately. Provider partial words can be journaled as unconfirmed text for manual review; they are not silently pasted as finalized recognition.

**Welcome and profile:** an optional display name/nickname, tour-completion flag and checklist preference are stored in local settings. The display name is not automatically added to speech prompts, recordings or Vocabulary. Clearing the name restores neutral greetings. The tour uses simulated audio visualization and does not request microphone access or make paid provider calls. Choosing audio recovery in the tour updates the existing local recovery preference; it does not enable successful-take training retention. You can exit without saving if local storage fails.
