# Community code of conduct

S2Teasy welcomes contributors regardless of background, experience, identity, accent, or disability. Help make this a useful and respectful place to collaborate.

Be considerate in issues, reviews, discussions, and code. Give specific, constructive feedback about behavior and evidence. Respect different communication styles and accessibility needs. Credit the work of others and handle disagreements without personal attacks.

Harassment, discriminatory language, threats, sexual attention, doxxing, and sharing private recordings or credentials without consent are unacceptable. Do not judge a speaker's intelligence or worth from their accent or recognition errors.

Maintainers may edit or remove content, lock conversations, or restrict participation to protect the community. Apply these rules fairly and explain moderation decisions when doing so will not expose private information.

To report a concern privately, use the contact method listed on the repository maintainer's GitHub profile and ask for a private channel before sending personal information. Do not post somebody else's private details in a public issue. Maintainers should handle reports confidentially, consider context, and avoid retaliation.

This applies to the repository and to project spaces where someone represents S2Teasy.
